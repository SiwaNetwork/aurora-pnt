# AURORA PNT — План разработки и моделирования

**Проект:** Собственная система навигации и синхронизации времени на базе LEO-созвездия  
**Инструмент:** aurora-pnt (Python, SGP4, numpy)  
**Дата составления:** 2026-05-04

---

## Архитектура системы

```
┌─────────────────────────────────────────────────────────┐
│                  LEO-спутники (PNT сегмент)             │
│   Бортовые атомные часы + PNT-сигнал + ISL (межспут.)   │
└────────────────────┬────────────────────────────────────┘
                     │ GSL (Ground-Satellite Link)
┌────────────────────▼────────────────────────────────────┐
│              Наземный сегмент управления (MCS)           │
│  Владимир · Железногорск · Хабаровск  + дружеств. стр.  │
└────────────────────┬────────────────────────────────────┘
                     │
┌────────────────────▼────────────────────────────────────┐
│                 Пользовательский сегмент                 │
│        Приёмники PNT (навигация + синхронизация)         │
└─────────────────────────────────────────────────────────┘
```

### ФАЗА 0 — Демонстратор технологии

**Цель:** Доказать что концепция работает. Проверить сигнал, бортовые часы,
связь с наземными станциями управления.

**Аналог в истории:** GPS Block I — 4 спутника (1978), позиционирование
несколько часов в сутки над полигоном.

| Параметр | Значение |
|---|---|
| Спутников | **3** |
| Орбитальных плоскостей | 1 |
| Высота | 1000 км |
| Наклонение | 87° |
| Покрытие | Прерывистое — 2–4 окна/сутки над МCS |
| Продолжит. окна | ~8–12 мин за проход |

**Наземные станции:** только Россия
- Владимир (56.1°N, 40.4°E)
- Железногорск (56.2°N, 93.5°E)
- Хабаровск (48.5°N, 135.1°E)

**Задачи моделирования:**
- [ ] Расчёт окон видимости (когда и сколько спутников над каждой MCS)
- [ ] Проверка геометрии (DOP при прохождении)
- [ ] Оценка продолжительности сеансов связи

**Конфиг:** `aurora/config/pnt/phase0_demo.yaml`

### ФАЗА 2 — Региональная система (Центральная Россия)

**Цель:** Непрерывное PNT покрытие центральной России —
от западной границы до Урала (49°N–65°N, 28°E–65°E).

| Параметр | Значение |
|---|---|
| Спутников | **120–144** |
| Орбитальных плоскостей | 10–12 |
| Высота | 1000 км |
| Наклонение | 87° |
| Покрытие | ~93–99% времени с 4+ спут. |
| PDOP p95 | 8–25 |

**Наземные станции:** Россия + дружественные страны
- Россия: Владимир, Железногорск, Хабаровск, Мурманск, Новосибирск, Владивосток
- Беларусь: Минск
- Казахстан: Алма-Ата
- Китай: Урумчи
- Иран: Тегеран
- Индия: Дели
- Куба: Гавана

**Задачи моделирования:**
- [ ] Тепловая карта покрытия по центральной России

- [ ] Поиск оптимальной конфигурации орбит

**Конфиг:** `aurora/config/pnt/phase2_regional.yaml`

### Высота орбиты (6×8 = 48 спут., центр. Россия)

| Высота | Покрытие 4+ | Ср. спутников |

| 8×12 | 96 | 77% | 56 |
| 10×12 | 120 | **93%** | **25** |
| 12×12 | 144 | **99.9%** | **8** |
| 10×14 | 140 | **~100%** | **10** |

## CLI — команды запуска

```bash
# Установка
pip install -e .

# Просмотр плана (без запуска)
aurora-pnt info -c aurora/config/pnt/phase0_demo.yaml

# Запуск одной симуляции
aurora-pnt run  -c aurora/config/pnt/phase0_demo.yaml \
                 -o results/phase0 -l phase0_demo

# Запуск параметрического эксперимента
aurora-pnt experiment -c aurora/config/pnt/experiments/sweep_altitude.yaml
```
