# Веб-симулятор группировки АВРОРА

Откройте `index.html` в браузере. 3D-глобус, орбиты Walker 300/15, модель КА, переключение фаз развёртывания (Ф0…Ф4).

Офлайн-режим требует локального Cesium — `aurora-pnt download-cesium` (каталог `assets/cesium/`). Иначе грузится с CDN (нужен интернет).

Пересборка: `python -m aurora.pnt.cli web-app`.
