# Пересборка ГОСТ-документа АВРОРА

Детерминированная сборка `AURORA_PNT_GOST.docx` (+ авто-PDF) из исходника
`AURORA_PNT_Technical_Project.md`. Порядок строгий — иначе теряется связность
или падает экспорт PDF.

Все команды — из корня проекта, с UTF-8 для консоли Windows:
префикс `PYTHONIOENCODING=utf-8 PYTHONUTF8=1`.

## Шаги

1. **Word не держит файл.** `AURORA_PNT_GOST.docx` должен быть закрыт в Word —
   иначе запись docx и экспорт PDF (Word COM) упадут. Если сборка падает с ошибкой
   доступа/COM — попросить пользователя закрыть документ в Word и повторить.

2. **Линтер связности (гейт).**
   `PYTHONIOENCODING=utf-8 PYTHONUTF8=1 python check_tp.py`
   Проверяет эмодзи, старые числа (0,114 / 0,279 / N_vis 42), устаревшую часовую
   схему (Cs вместо CSAC), штампы версий. Если НЕ «связность ОК» — показать
   нарушения и НЕ собирать, пока не исправлено (линтер подключён Stop-хуком).

3. **Битые ссылки на рисунки.** Проверить, что все `![](path)` существуют:
   ```
   PYTHONIOENCODING=utf-8 python -c "import re,os; md=open('AURORA_PNT_Technical_Project.md',encoding='utf-8').read(); miss=[p for p in re.findall(r'!\[[^\]]*\]\(([^)]+)\)',md) if not os.path.exists(p)]; print('битых ссылок:',len(miss)); [print('  НЕТ:',m) for m in miss]"
   ```
   Если есть отсутствующие — сгенерировать недостающий рисунок (`aurora-pnt <модуль>`)
   или поправить путь до сборки.

4. **Сборка.**
   `PYTHONIOENCODING=utf-8 PYTHONUTF8=1 python convert_gost.py`
   Скрипт собирает docx по ГОСТ и сразу экспортирует PDF через Word COM
   (обновляет оглавление автоматически). Ожидаемый вывод: строки `Готово! … КБ` и
   `PDF: … (Word COM; оглавление обновлено)`. Флаг `--no-pdf` пропускает PDF.

5. **Отчёт.** Сообщить: статус линтера, число битых ссылок (0), размеры/пути
   docx и PDF, что изменилось.

## Правила

- **Не коммитить** результат без явной просьбы пользователя (правило проекта).
- При изменении канонических величин (часы/фазы/точность/LCC) сперва провести
  сквозную правку (ТП + генераторы рисунков в `aurora/pnt/` + ОКР-доки
  `docs/`), затем регенерировать затронутые рисунки и только потом собирать.
- Канонические решения и стиль — в `CLAUDE.md` и памяти проекта; здесь только
  процедура сборки.
