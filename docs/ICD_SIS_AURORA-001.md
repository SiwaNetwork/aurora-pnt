## 1. Введение

### 1.1 Назначение документа

Настоящий документ устанавливает требования к интерфейсу Signal-in-Space (SIS) низкоорбитальной навигационной системы AURORA PNT, включая радиочастотные параметры, формат навигационного сообщения, точностные характеристики и протоколы совместимости с действующими ГНСС.

### 1.2 Область применения

ICD-AURORA-001 распространяется на:

- Бортовой навигационный передатчик КА AURORA-LEO (300 космических аппаратов);
- Наземные пользовательские приёмники (профессиональные и массового сегмента);
- Контрольно-измерительные станции системы AURORA.

### 1.3 Ссылочные документы

## 2. Радиочастотные характеристики

### 2.1 Несущие частоты

| Параметр | L1 | L5 |
|---|---|---|
| Центральная частота, МГц | 1575,420 | 1176,450 |
| Ширина полосы излучения, МГц | ±20,46 (3 дБ) | ±10,23 (3 дБ) |
| Долговременная стабильность | $\pm 1\cdot10^{-13}$ | $\pm 1\cdot10^{-13}$ |
| Кратковременная (Allan, τ=1 с) | $\le 5\cdot10^{-12}$ | $\le 5\cdot10^{-12}$ |
| Тип источника | Рубидиевый стандарт, резерв — кварц TCXO | --- |

### 2.2 Поляризация

Излучаемая поляризация — **правосторонняя круговая (RHCP)** на обеих частотах.
Коэффициент эллиптичности на оси: ≤ 1,2 дБ.

### 2.3 Мощность и диаграмма направленности

| Параметр | Значение |
|---|---|
| Выходная мощность передатчика | 5 Вт (+37 dBm) |
| Усиление антенны (зенит) | 15 dBi |
| EIRP (зенит) | **+7 dBW** |
| EIRP (10° над горизонтом для пользователя) | +4 dBW |
| Ширина ДН по уровню –3 дБ | 60° |
| Уровень кросс-поляризации | ≤ –20 дБ |

EIRP определяется по формуле:

$$\text{EIRP} = P_{TX} + G_{ANT} - L_{ALD}$$

где $P_{TX} = 37$ dBm, $G_{ANT} = 15$ dBi, $L_{ALD} = 2$ дБ (потери в антенно-фидерном тракте).

## 3. Модуляция и кодирование

### 3.1 Сводная таблица сигналов

| Сигнал | Модуляция | Чип-рейт, МГц | Длина кода | Период кода, мс | Тип |
|---|---|---|---|---|---|
| L1-D (data) | BOC(1,1) | 1,023 | 10230 | 10 | OS data |
| L1-P (pilot) | TMBOC(6,1,4/33) | 1,023 / 6,138 | 10230 | 10 | OS pilot |
| L5-D (data) | BPSK(10) | 10,230 | 10230 | 1 | OS data |
| L5-P (pilot) | BPSK(10) | 10,230 | 10230 | 1 | OS pilot |

### 3.2 Сигнал L1-D

- **Модуляция:** Binary Offset Carrier BOC(1,1) с поднесущей 1,023 МГц.
- **Скорость данных:** 50 бит/с, после канального кодирования FEC ½ конволюционного — **250 sps**.
- **Длина дальномерного кода:** 10 230 чипов.
- **Период повторения:** 10 мс.
- **Распределение мощности:** L1-D = 25 % суммарной L1.

Нормированный спектр BOC(1,1):

$$G_{BOC(1,1)}(f) = T_c \cdot \text{sinc}^2(\pi f T_c) \cdot \tan^2\left(\frac{\pi f T_c}{2}\right)$$

### 3.3 Сигнал L1-P

- **Модуляция:** TMBOC(6,1,4/33). 29 чипов BOC(1,1) + 4 чипа BOC(6,1) в каждом блоке из 33 чипов.
- **Кодовая последовательность:** Weil-коды длиной $L = 10\,223$ + 7 chips зашивки, итого 10 230.
- **Распределение мощности:** L1-P = 75 % суммарной L1.

### 3.4 Сигнал L5

- **L5-D:** BPSK с чип-рейтом 10,23 Мчип/с, данные 100 бит/с (50 бит/с после FEC ½).
- **L5-P:** BPSK(10), длина 10 230, Extended Memory Codes из библиотеки AURORA-PRN-5.
- **Распределение мощности:** L5-D = 50 %, L5-P = 50 %.
- **Вторичный код (Neuman-Hofman):** NH20 на data-канале, NH10 на pilot-канале.

### 3.5 Канальное кодирование

- Свёрточный код, $K = 7$, $r = 1/2$, полиномы $G_1 = 171_8$, $G_2 = 133_8$ (стандарт ИКАО, NASA).
- Перемежение блочное 30×10 (300 символов).
- Контрольная сумма: CRC-24Q (полином GPS L5), охват — субкадр без CRC-поля.

## 4. Структура навигационного сообщения ANAV

### 4.1 Общая структура кадра

| Параметр | Значение |
|---|---|
| Длина кадра | 1800 бит |
| Число субкадров | 6 |
| Длина субкадра | 300 бит |
| Длительность субкадра | 5 с (L1 при 50 бит/с) |
| Длительность кадра | **30 с** |
| Полный цикл (12 кадров) | 6 мин |

### 4.2 Содержимое субкадров

#### Субкадр 1 — Часовые параметры (clock)

| Поле | Бит | Описание | Масштаб |
|---|---|---|---|
| Preamble | 8 | 0x8B (1000 1011) | --- |
| PRN ID | 9 | 200–499 | --- |
| TOW | 17 | Time of Week, с | 6 |
| $a_{f0}$ | 22 | Bias времени | $2^{-31}$ с |
| $a_{f1}$ | 16 | Drift | $2^{-43}$ с/с |
| $a_{f2}$ | 8 | Drift rate | $2^{-55}$ с/с² |
| $T_{GD}$ | 8 | Group delay L1–L5 | $2^{-31}$ с |
| IODE | 8 | Issue of Data, Ephemeris | --- |
| Резерв + CRC-24Q | 204 | --- | --- |

Расчёт поправки часов:

$$\Delta t_{SV} = a_{f0} + a_{f1}(t - t_{oc}) + a_{f2}(t - t_{oc})^2 - T_{GD}$$

#### Субкадр 2-3 — Эфемериды (16 параметров Кеплера)

| Параметр | Описание |
|---|---|
| $M_0$ | Средняя аномалия в эпоху |
| $\Delta n$ | Поправка к среднему движению |
| $e$ | Эксцентриситет |
| $\sqrt{a}$ | Корень из большой полуоси |
| $\Omega_0$ | Долгота восходящего узла |
| $i_0$ | Наклонение в эпоху |
| $\omega$ | Аргумент перигея |
| $\dot{\Omega}$ | Скорость прецессии узла |
| IDOT | Скорость изменения наклонения |
| $C_{uc}, C_{us}$ | Гармоники аргумента широты |
| $C_{rc}, C_{rs}$ | Гармоники радиуса |
| $C_{ic}, C_{is}$ | Гармоники наклонения |
| $t_{oe}$ | Опорное время эфемерид |

Точность представления: 32 бита знакового числа с фиксированной запятой для большинства параметров.

#### Субкадр 4 — Ионосферные коэффициенты и UTC

- 8 параметров Klobuchar: $\alpha_0..\alpha_3, \beta_0..\beta_3$.
- Параметры UTC: $A_0$, $A_1$, $t_{ot}$, $W_t$, $\Delta t_{LS}$.

Модель ионосферы (Klobuchar):

$$T_{iono} = F \cdot \left[ 5\cdot10^{-9} + AMP \cdot \left(1 - \frac{x^2}{2} + \frac{x^4}{24}\right) \right]$$

#### Субкадр 5 — Альманах

- Сокращённые эфемериды всех 300 КА созвездия.
- Период обновления 12 часов.
- Полный альманах передаётся за 12 кадров (6 минут).

#### Субкадр 6 — TESLA MAC

- 128 бит ключевой цепочки HMAC-SHA256.
- Идентификатор ключа (KeyID): 8 бит.
- Метка времени применения ключа: 16 бит.
- TruncatedMAC: 96 бит на текущий кадр.

## 5. Параметры точности

### 5.1 Бюджет ошибок

| Источник ошибки | $\sigma$, м |
|---|---|
| Эфемериды (radial) | 0,07 |
| Часы | 0,06 |
| Групповая задержка | 0,02 |
| Шум модели | 0,05 |
| **URE (RSS)** | **0,11** |
| **SISA = 1,1 × URE** | **≈ 0,12** |

Значение SISA, передаваемое в навигационном сообщении: округление вверх по таблице SISA-индексов (поле 4 бита).

### 5.2 Сводный пользовательский бюджет (UERE) для двухчастотного приёмника

$$\sigma_{UERE} = \sqrt{\sigma_{SIS}^2 + \sigma_{iono}^2 + \sigma_{tropo}^2 + \sigma_{mp}^2 + \sigma_{rx}^2}$$

При свободной ионосфере (L1+L5): $\sigma_{UERE} \approx 0,5$ м (1σ).

### 5.3 Целевые показатели сервиса

| Сервис | Точность (95 %) | Доступность |
|---|---|---|
| Open Service (OS) | ≤ 2,5 м (горизонталь) | ≥ 99 % |
| PPP с быстрой сходимостью | ≤ 0,2 м (по плановой) | ≥ 95 % |
| RTK + LEO augmentation | ≤ 0,05 м | ≥ 90 % |

## 6. Совместимость с ГНСС

### 6.1 GPS L1C

- BOC(1,1) и TMBOC AURORA полностью совместимы с GPS L1C.
- Взаимная корреляция Weil-кодов AURORA ↔ GPS: пик ≤ −61 дБ/Гц.
- Спектральная сепарация (Spectral Separation Coefficient): SSC ≤ −78 дБ-Гц.

### 6.2 Galileo E1 OS

- Полная спектральная совместимость (BOC(1,1)).
- Координация PRN-диапазонов с ESA по соглашению AURORA-ESA-2025.

### 6.3 L5 / E5a

- BPSK(10) совместим с GPS L5 и Galileo E5a.
- Кодовое разделение по библиотеке Memory Codes AURORA-PRN-5.

### 6.4 ГЛОНАСС L3OC

- Сосуществование без помех (разнесение по частоте: ΔF ≥ 23 МГц от L1OF, ΔF ≥ 30 МГц от L3OC).

## 7. Идентификация и аутентификация

### 7.1 Распределение PRN

| Диапазон | Назначение |
|---|---|
| 1–63 | GPS |
| 64–96 | Galileo |
| 97–158 | ГЛОНАСС (резерв) |
| 159–199 | BeiDou |
| **200–499** | **AURORA PNT** |
| 500–510 | Резерв ITU |

### 7.2 TESLA-аутентификация

Протокол Timed Efficient Stream Loss-tolerant Authentication:

- Криптографический примитив: **HMAC-SHA256**.
- Длина ключа: 256 бит, передаётся усечённым до 128 бит.
- Период ротации ключа: **30 с** (1 кадр).
- Глубина цепочки: 4 320 ключей (= 1,5 суток).
- Опубликование ключа: с задержкой 1 субкадр (5 с) — препятствует подделке.

Проверка ключа:

$$K_{i-1} = H(K_i)$$

где $H$ — SHA-256, $K_i$ — текущий ключ.

### 7.3 Идентификация системного времени

- Системное время AURORA: GPST-совместимое, привязка к UTC(SU) через ВНИИФТРИ.
- Смещение AURORA-T относительно UTC(SU): ≤ 5 нс (1σ).

## 8. Доплер и динамика

### 8.1 Геометрия LEO-сигнала

Для орбиты h = 1000 км, i = 75°, при наблюдении пользователем на земле:

| Параметр | Значение |
|---|---|
| Орбитальная скорость КА | 7,35 км/с |
| Максимальная радиальная скорость | 7,33 км/с |
| Максимальный Доплер L1 | **±38,6 кГц** |
| Максимальный Доплер L5 | ±28,8 кГц |
| Скорость изменения Доплера (L1) | **38,6 Гц/с** |
| Скорость изменения Доплера (L5) | 28,8 Гц/с |

Расчёт Доплеровского сдвига:

$$f_D = -\frac{v_r}{c} \cdot f_0$$

где $v_r$ — радиальная составляющая скорости, $f_0$ — несущая частота.

### 8.2 Требования к приёмнику

| Параметр | Требование |
|---|---|
| Диапазон поиска по частоте | ±50 кГц (с учётом нестабильности кварца) |
| Шаг поиска | ≤ 250 Гц |
| Минимальная полоса PLL | **≥ 1,4 Гц** (рекомендация ≥ 5 Гц) |
| Время первого захвата (TTFF) | ≤ 30 с (hot start), ≤ 90 с (cold start) |
| Чувствительность отслеживания | C/N₀ ≥ 25 дБ-Гц |

## 9. Бюджет линии связи

### 9.1 Расчёт C/N₀ для L1 в зените

| Параметр | Значение |
|---|---|
| EIRP КА | +7 dBW |
| Потери в свободном пространстве, FSPL (1000 км, 1575 МГц) | −156,4 дБ |
| Усиление приёмной антенны (хемисфера) | +3 dBi |
| Поляризационные потери | −0,5 дБ |
| Атмосферные потери | −0,5 дБ |
| Принимаемая мощность $P_r$ | **−147,4 dBW** |
| Системная шумовая температура $T_{sys}$ | 290 K |
| Спектральная плотность шума $N_0$ | −203,98 dBW/Гц |
| **C/N₀ (зенит)** | **52,6 дБ-Гц** |
| **C/N₀ (10° над горизонтом)** | **43,6 дБ-Гц** |

Формула:

$$\frac{C}{N_0} = \text{EIRP} - L_{FSPL} + G_{RX} - L_{misc} - 10\log_{10}(k T_{sys})$$

где $k = 1{,}38\cdot10^{-23}$ Дж/К — постоянная Больцмана.

### 9.2 Маржа

- Целевой C/N₀ при отслеживании: 30 дБ-Гц.
- Маржа в зените: **22,6 дБ**.
- Маржа при 10°: **13,6 дБ**.
