## 1. Введение

### 1.1 Назначение документа

Настоящий документ определяет интерфейс межспутниковых каналов связи (Inter-Satellite Links, ISL) низкоорбитальной навигационной системы AURORA PNT. ISL используются для:

- Измерения дальности и взаимной синхронизации часов между КА (Two-Way Time and Frequency Transfer, TWTFT);
- Распространения системного времени AURORA-T при отсутствии связи с наземным сегментом;
- Передачи навигационных данных, поправок и команд между КА;
- Поддержания целостности созвездия в режиме «автономного полёта» (до 72 ч без наземной связи).

### 1.2 Область применения

ICD-AURORA-002 применяется к:

- Бортовым приёмо-передатчикам Ka-диапазона КА AURORA-LEO;
- Бортовому контроллеру ISL-сети (БКС-ISL);
- Алгоритмам автономной орбитальной навигации (Autonomous Orbit Determination, AOD).

## 2. Топология ISL-сети

### 2.1 Параметры созвездия

| Параметр | Значение |
|---|---|
| Тип созвездия | Walker Delta 300/15/1 |
| Число КА | 300 |
| Число плоскостей | 15 |
| КА в плоскости | 20 |
| Высота орбиты | 1000 км |
| Наклонение | 75° |
| Угловое расстояние между КА в плоскости | 18° |
| Угловое разделение плоскостей по узлу | 24° |

### 2.2 Конфигурация ISL на каждом КА

Каждый КА оснащён **4 каналами ISL**:

| Канал | Назначение | Соседний КА |
|---|---|---|
| ISL-1 | Внутриплоскостной +1 | Следующий по фазе в той же плоскости |
| ISL-2 | Внутриплоскостной −1 | Предыдущий по фазе в той же плоскости |
| ISL-3 | Межплоскостной +1 | Ближайший в соседней плоскости (восток) |
| ISL-4 | Межплоскостной −1 | Ближайший в соседней плоскости (запад) |

### 2.3 Геометрические параметры

| Параметр | Внутриплоскостной | Межплоскостной |
|---|---|---|
| Расстояние между КА, км | **≈ 2 310** | **≈ 3 063** |
| Угол отклонения от орбитальной плоскости, ° | 0 | ±12 (зависит от широты) |
| Антенный механизм | Фиксированная антенна | **Поворотный** |
| Диапазон углов сканирования | ±5° | ±60° по азимуту, ±20° по углу места |

Расчёт расстояния между КА в одной плоскости:

$$d_{\text{intra}} = 2 (R_E + h) \sin\left(\frac{\Delta\phi}{2}\right) = 2 \cdot 7378 \cdot \sin(9°) \approx 2310 \text{ км}$$

Межплоскостной (на экваторе при максимальном сближении):

$$d_{\text{inter}} \approx 2 (R_E + h) \sin\left(\frac{\Delta\Omega \sin i}{2}\right) \approx 3063 \text{ км}$$

### 2.4 Граф связности

Топология формирует регулярный тороидальный граф степени 4. Диаметр графа: ≤ 15 хопов между любыми двумя КА. Среднее число хопов: 7,5.

## 4. Сигнал и модуляция

### 4.1 Структура сигнала

ISL-сигнал состоит из двух компонент, мультиплексированных по времени (TDMA внутри 10-секундного сеанса):

| Компонента | Длительность | Назначение |
|---|---|---|
| Dual-tone | 100 мс | Two-Way Time and Frequency Transfer (TWTFT) |
| Data BPSK(50) | 9,9 с | Псевдодальность + обмен данными |

### 4.2 Dual-tone TWTFT

- Две когерентные несущие: $f_1 = 26{,}500$ ГГц, $f_2 = 26{,}510$ ГГц.
- Разнос 10 МГц для разрешения целочисленной фазовой неоднозначности.
- Точность фазовых измерений: ≤ 5 мм (1σ).

Принцип TWTFT — два КА одновременно передают и принимают друг друга:

$$\Delta\tau_{AB} = \frac{(T_2 - T_1) - (T_4 - T_3)}{2}$$

$$D_{AB} = \frac{c \cdot [(T_2 - T_1) + (T_4 - T_3)]}{2}$$

где $\Delta\tau_{AB}$ — разность хода часов, $D_{AB}$ — дальность.

### 4.3 BPSK(50) широкополосный сигнал

- **Модуляция:** BPSK.
- **Чип-рейт:** 50 Мчип/с.
- **Длина дальномерного кода:** 32 767 чипов (m-последовательность).
- **Период кода:** 0,655 мс.
- **Скорость передачи данных:** 2 Мбит/с (после FEC ¾).
- **Канальное кодирование:** LDPC (8160, 6120), пакетная защита CRC-32.

Точность кодовых измерений:

$$\sigma_{code} = \frac{c}{\text{Chip Rate}} \cdot \frac{1}{\sqrt{2 \cdot C/N_0 \cdot T_{int}}}$$

При $C/N_0 = 75$ дБ-Гц, $T_{int} = 1$ с: $\sigma_{code} \approx 5$ см.

### 4.4 Псевдошумовые коды

- Семейство m-последовательностей с порождающим полиномом $g(x) = x^{15} + x + 1$.
- Распределение PRN-кодов ISL: 1–300 (по номеру КА).

## 5. Протокол обмена

### 5.1 Формат сообщения ISL-MSG

| Поле | Размер, бит | Описание |
|---|---|---|
| Sync Pattern | 24 | 0xACFFE3 (стандарт CCSDS) |
| Source SVID | 9 | ID отправителя (1–300) |
| Destination SVID | 9 | ID получателя |
| Message Type | 8 | См. таблицу 5.2 |
| Timestamp | 32 | GPS time of week, шаг 1 мс |
| Payload | 96 | См. ниже |
| HMAC | 16 | Усечённая аутентификация |
| CRC-16 | 16 | Контрольная сумма |
| **Итого** | **200** | --- |

### 5.2 Типы сообщений

| Type | Mnemonic | Описание |
|---|---|---|
| 0x01 | POS_STATE | Координаты + скорости КА (ECEF, EME2000) |
| 0x02 | CLK_OFFSET | Часовая поправка + дрейф |
| 0x03 | STATUS | Состояние БА, температуры, напряжения |
| 0x04 | EPHEM_UPDATE | Обновление эфемерид |
| 0x05 | RANGE_MEAS | Результат двусторонней дальнометрии |
| 0x06 | KEY_DIST | Распределение сеансовых ключей |
| 0x07 | ALERT | Аварийное сообщение (приоритет) |
| 0x08 | MANEUVER | Уведомление о манёвре (упреждение) |

### 5.3 Расписание обмена

| Режим | Период обмена | Условие |
|---|---|---|
| Штатный | **10 с** | Нормальная работа |
| Усиленный | **1 с** | Манёвры, заходы в тень, СБЭ |
| Аварийный | 100 мс | Сигнал ALERT от любого КА |
| Холостой | 60 с | Дежурный режим (заряд АБ) |

### 5.4 Алгоритмы маршрутизации

- **Протокол:** AURORA Distance-Vector Routing (ADVR), модификация RIP с учётом качества канала.
- Метрика стоимости: $W = N_{hops} + \alpha (1 - C/N_0/C/N_{0,ref})$, $\alpha = 0{,}3$.
- Обновление таблицы маршрутизации: каждые 60 с.

## 6. Безопасность

### 6.1 Шифрование

- **Алгоритм:** AES-128-GCM (в режиме Galois/Counter Mode).
- **Длина ключа:** 128 бит.
- **Векторы инициализации (IV):** 96 бит, уникальный на каждое сообщение.
- **Аутентификационный тег:** 128 бит.

Альтернативный режим для российской криптографии: ГОСТ Р 34.12-2015 «Кузнечик», 128-бит блок.

### 6.2 Распределение ключей

- **Master Key:** загружается с земли при каждом сеансе TT&C (S-band).
- **Session Key:** генерируется бортовым ГПСЧ (DRBG SP800-90A) по запросу.
- **Длительность сеанса:** 24 ч.
- **Метод доставки на соседний КА:** ECDH с эфемерными ключами на кривой P-256 + подпись (Стрибог-256 для российского контура).

### 6.3 Аутентификация

- HMAC-SHA-256, усечённая до 16 бит в поле сообщения (для экономии bandwidth).
- Защита от replay-атак: монотонный счётчик 32 бита, дрейф окна ±60 с.

### 6.4 Защита от спуфинга

- Контроль когерентности измерений дальности и часов (≥ 3 соседних КА).
- Защитные пороги: $|\Delta \rho| < 50$ м, $|\Delta t| < 100$ нс.
- При нарушении: сообщение ALERT и переход в режим «карантина».

## 7. Точностные параметры

### 7.1 Дальнометрические измерения

| Параметр | Требование | Достигаемое |
|---|---|---|
| Кодовая псевдодальность $\sigma_{code}$ | ≤ 10 см | **5 см** |
| Фазовая (carrier-phase) $\sigma_{\phi}$ | ≤ 10 мм | **5 мм** |
| Систематическая ошибка (bias) | ≤ 2 см | 1 см (после калибровки) |
| Время измерения | 1 с | 1 с |

### 7.2 Синхронизация часов

| Параметр | Требование | Достигаемое |
|---|---|---|
| Точность синхронизации $\sigma_{clk}$ | ≤ 1 нс | **0,5 нс** |
| Долговременная стабильность (Allan, τ = 1 сут) | $\le 1\cdot10^{-13}$ | $5\cdot10^{-14}$ |
| Период переоценки | 10 с | 10 с |
| Время удержания (без TWTFT) | 72 ч с деградацией ≤ 5 нс | 60 ч (при штатных условиях) |

### 7.3 Автономное определение орбиты (AOD)

- Без связи с землёй: ошибка 3D-орбиты ≤ **1 м** за 24 ч, ≤ **3 м** за 72 ч.
- Алгоритм: расширенный фильтр Калмана (EKF) c учётом измерений ISL ↔ соседних 4 КА.
- Используемая модель сил: гармоники гравиполя до 70×70, J2-возмущения, light pressure, Earth albedo.

### 8.1 Требования к наведению

| Параметр | Значение |
|---|---|

| Угловая скорость отслеживания | до 0,2 °/с |
| Угловое ускорение | до 0,05 °/с² |

### 8.2 Процедура захвата

| Этап | Длительность, с | Описание |
|---|---|---|
| Предвычисление направлений | 5 | По эфемеридам соседа |
| Грубое наведение | 10 | Привод антенны → ±1° |
| Поиск несущей | 20 | Сканирование ±100 кГц |
| Захват PLL | 10 | Затягивание частоты и фазы |
| Захват кода | 10 | Синхронизация PRN-кода |
| Аутентификация | 5 | HMAC + обмен ключами |
| **Итого захват** | **≤ 60** | --- |

### 8.3 Удержание связи

- Если C/N₀ падает ниже 65 дБ-Гц на 5 с — переход на резервный путь.
- Если канал не восстановлен за 30 с — оповещение Mission Control (ICD-AURORA-003).

### 9.2 Расчёт для межплоскостного канала (3063 км)

| Параметр | Значение |
|---|---|
| EIRP | +35 dBW |
| FSPL (26,5 ГГц, 3063 км) | $-130{,}6$ дБ |
| Потери на расходимость, поляризацию | −1,5 дБ |
| Принимаемая мощность $P_r$ | −72,1 dBW |
| **C/N₀** | **≈ 86,5 дБ-Гц** |
| Маржа | **+16,5 дБ** |

### 9.3 Формулы и проверка

FSPL рассчитывается как:

$$L_{FSPL} = 20\log_{10}\left(\frac{4 \pi d f}{c}\right)$$

Для $d = 3063$ км, $f = 26{,}5$ ГГц: $L_{FSPL} \approx 130{,}6$ дБ.

**Маржа линии связи:** > 6 дБ во всех режимах работы (запас на старение, тепловые эффекты и облучение).
